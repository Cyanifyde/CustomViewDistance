# PlayerViewDistance

Server-side Fabric mod for Minecraft `26.1` that loads and sends chunks based on each player's own render distance.

## Requirements

- Java `25`
- Minecraft `26.1`
- Fabric Loader `0.18.5`

## Build

```powershell
.\gradlew.bat build
```

Built jars are written to `build/libs/`.

## Notes

- This is a dedicated-server mod.
- The default config file is `config/playerviewdistance.json`.
